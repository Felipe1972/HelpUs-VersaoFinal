# Help Us

Aplicativo mobile assistivo para autenticação e gerenciamento básico de usuários.

## Estrutura inicial

- `backend/`: futura API REST em Node.js e Express.
- `mobile/`: futuro aplicativo React Native executado com Expo Go.
- `database/`: futuro script MySQL da primeira entrega.

Nesta etapa, somente a estrutura inicial e os exemplos de configuração foram criados.
Nenhuma dependência foi instalada e nenhum banco de dados foi alterado.
